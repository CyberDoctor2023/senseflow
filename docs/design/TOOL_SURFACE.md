# 圆形控件表面规范

普通出现采用 matchedGeometry 与 easeInOut；背景不得参与覆盖历史内容的上层融合。拖动时唯有实际目的工具与拖动卡片参与同一个容器，其他工具与左侧筛选隔离。形变与内容载荷分离，不在指针移动中做 SQL、文件读取或图片解码。

验证分开记录：构建、静态基线/可读性、实际拖动融合、取消回程；构建通过不能代替后两项。

### 背景关闭事件与退场焦点
预览打开时，工作区内卡片/工具操作仍正常传递；工作区背景的一次点击只负责收回预览，成功接收关闭请求后不再传递给底层窗口。避免底层在预览仍可见时抢夺 key 状态。其他应用/设置窗口的正常点击不拦截。

### 显式填入结果
工具请求开始时捕获剪贴板呼出前的外部 NSRunningApplication 实例，结果与该目标绑定。按钮显示「填入 应用名」，由用户主动触发；目标退出、senseflow 自身或缺少辅助功能权限时拒绝自动填入并保留可复制结果。填入恢复目标应用后沿用 AutoPasteManager 的前台 PID 校验，只发送粘贴，不发送回车。该机制恢复应用当前输入焦点，不承诺恢复应用内部已改变的光标位置。固定模式不收起历史面板。

填入返回值必须等到目标激活、延迟后的前台 PID 与剪贴板 changeCount 校验、键盘事件创建/发送后才确定。任何检查失败均不发 Cmd+V，结果正文保留，界面提示可手动复制。该返回值仅证明事件已发送，不等于第三方输入框已接受内容；不能显示「填入成功」的未经验证承诺。
填入操作只允许一个在途请求；发送期间禁用重复填入与工具启动，防止双击创建多次粘贴。状态保留为「已发送粘贴」或「请复制后粘贴」，不定时清除。

### 拖动表面交接验收补充
source 卡片、窗口内 live surface、跨窗 native drag image 与取消回程必须使用同一视觉尺寸与内容缩放合同。名义布局尺寸不等于按压/hover 后视觉尺寸；禁止用名义截图截断放大后的玻璃边缘。需通过首帧交接、窗口边缘切换、取消回位三段实测验证，不以静态截图或颜色相近替代。

拖动尺寸实现：指针区域继续采用固定布局槽位做事件命中；visualScale 单独描述卡片视觉放大。native 拖动截图/draggingFrame/live screen frame 使用同一按中心扩展后的矩形，live 内容与圆角随实际 drag frame 比例缩放。回程目标使用去除按压后的 hover/preview 静止比例。SwiftUI 按压动画中途的实际呈现比例仍需运行验证，不能把目标比例当作逐帧测量。
