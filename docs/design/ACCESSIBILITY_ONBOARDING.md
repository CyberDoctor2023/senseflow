# 辅助功能引导

目标：在现有教程分类步骤之后解释直接粘贴权限；打开真实系统设置，并把可拖动应用图标的指引停靠在旁边。授权自动继续；稍后开启继续教程。读取剪贴板不依赖此权限。

非目标：恢复旧三权限页面、模拟系统设置、使用私有 TCC API、请求录屏权限来定位窗口。

结构：教程协调器只管理步骤；独立权限引导控制器管理面板、系统设置窗口元数据与授权轮询。仅引导期间每 250ms 检查一次；系统设置离开前台时隐藏卡片，返回时恢复。离开步骤、关闭或超时结束任务。屏幕坐标转换使用主屏坐标原点，按实际可见屏幕夹紧布局。系统窗口不可定位时不编造位置，保留原入口可重试。

视觉：同一张圆角指引从触发位置移至设置旁，支持减少动态效果；白色简洁内容、应用图标、短句，不额外申请权限。系统设置中的授权由用户操作。

验收：构建；实际打开设置检查首次定位、移动跟随、切换应用隐藏/恢复、稍后开启、授权后继续。未实际执行的项目不得标为通过。
