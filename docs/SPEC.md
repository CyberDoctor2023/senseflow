## 项目目标

macOS 剪贴板管理器，支持自动捕获、搜索、OCR、自动粘贴、Prompt Tools 集成

## 功能范围

### 已实现

- ✅ 剪贴板自动捕获（文本、图片）
- ✅ 全局快捷键呼出历史面板（Cmd+Shift+V，可自定义）

## 核心模块

### 1. 数据库管理

**表结构** (`clipboard_history`):
- id: INTEGER PRIMARY KEY
- unique_id: TEXT UNIQUE (SHA256 hash)
- type: TEXT ('text' | 'image')
- text_content: TEXT
- image_data: BLOB (\u003c512KB)
- blob_path: TEXT (\u003e512KB)
- timestamp: INTEGER
- app_name: TEXT
- app_path: TEXT
- ocr_text: TEXT

**功能**:
- SHA256 去重
- 200 条上限管理（可调 50-500，FIFO）
- 大文件分离存储（\u003e512KB → blobs/ 目录）
- 后台 OCR 识别（Vision Framework）

### 2. 剪贴板监听

**轮询**: 0.75 秒检查 `NSPasteboard.changeCount`

**敏感数据过滤**:
- org.nspasteboard.TransientType
- org.nspasteboard.ConcealedType
- org.nspasteboard.AutoGeneratedType

**暂停机制**: 写入剪贴板时暂停 1 秒（避免自己捕获）

### 3. 悬浮窗管理

**窗口规范** (v0.2.1):
- 位置: 屏幕底部居中，距底部 20pt
- 高度: 280pt
- 圆角: 20pt（macOS 26 系统级应用标准）
- 背景: `.glassEffect(.regular)`
- 显示动画: `.snappy(duration: 0.4, extraBounce: 0.0)`
- 隐藏动画: `.smooth(duration: 0.3, extraBounce: 0.0)`

**卡片规范**:
- 尺寸: 180×180pt（正方形）
- 圆角: 20pt
- 间距: 12pt
- 色条: 3pt（文本蓝 #007AFF，图片紫 #AF52DE）
- 背景: `.thinMaterial`
- 悬停: 1.05x 放大 + 阴影加深

### 4. 全局快捷键

- 默认: Cmd+Shift+V（可自定义）
- API: 已有 KeyboardShortcuts 组合键注册
- 冲突检测: 启动时临时注册测试
- 支持修饰键: Cmd、Option、Shift、Control 任意组合

### 5. 自动粘贴

- CGEvent 模拟 Cmd+V
- Accessibility 权限检查
- 焦点切换 + 0.3 秒延迟
- 参考 Maccy 实现

### 6. 搜索功能

- 实时过滤（300ms 防抖）
- 搜索范围: textContent || appName || ocrText
- 支持图片 OCR 文本搜索
- 文本操作: Cmd+A/C/V/X

### 7. 图片 OCR

- Vision Framework (VNRecognizeTextRequest)
- 后台异步执行（Task.detached）
- 语言支持: 中文简繁体、英文
- 精确模式 + 语言校正

### 8. 设置面板

**布局**（2026-10-07）：自定义双栏、统一苹方、senseflow 小写、一体标题栏。最小600×500pt，默认850×620pt。

**分类**：
1. 通用：登录时启动。
2. 快捷键：单个打开剪贴板录制控件、恢复默认；不重复当前/默认快捷键文本。
3. 隐私：应用排除、必要的权限状态和数据说明。
4. 一组工具：工具列表与账号/模型配置。

不提供历史条数上限、自动粘贴开关、使用指南或卡片操作说明。点击卡片默认粘贴。历史不按条数自动删除，摘要200条分页、末尾继续读取，原文/图片按需加载。详细验收见 `design/SETTINGS_MINIMAL_2026-10-07.md`。

## 架构设计

### Clean Architecture（整洁架构）

项目采用 Clean Architecture，实现业务逻辑与框架解耦：

**架构层次**（依赖方向：外层 → 内层）：

1. **Domain Layer（领域层）**
   - Protocols（接口定义）：AIServiceProtocol, ClipboardReader, NotificationServiceProtocol 等
   - Value Objects（值对象）：ToolID, KeyCombo, ClipboardContent
   - Errors（领域错误）：PromptToolError

2. **Use Case Layer（用例层）**
   - ExecutePromptTool：执行 Prompt 工具
   - RegisterToolHotKey：注册工具快捷键
   - AnalyzeAndRecommend：Smart AI 分析推荐

3. **Coordinator Layer（协调器层）**
   - PromptToolCoordinator：协调 Prompt 工具相关用例
   - SmartToolCoordinator：协调 Smart AI 相关用例

4. **Adapter Layer（适配器层）**
   - Services：NSPasteboardAdapter, OpenAIServiceAdapter, UserNotificationAdapter
   - Repositories：SQLitePromptToolRepository

5. **Infrastructure Layer（基础设施层）**
   - DI Container：DependencyContainer, DependencyEnvironment
   - Legacy Managers：DatabaseManager, HotKeyManager 等（逐步迁移中）

**核心原则**：
- **依赖倒置**：业务逻辑依赖接口，不依赖具体实现
- **单一职责**：每个类只有一个变化原因
- **接口隔离**：小而专注的接口定义
- **依赖注入**：通过构造器注入依赖，便于测试

**详细文档**：
- `docs/ARCHITECTURE_TEACHING_GUIDE.md` - 完整架构教学指南
- 代码中包含详细的教学注释

## 2026-10-06：顶部类型筛选

仅保留“文本”“图片”，点击立即筛选当前历史/搜索结果对应类型，有明确选中反馈。再点已选类型恢复全部，不新增“应用”入口。搜索与类型组合；后续刷新继续遵守当前筛选，不更改原记录。筛选排除正在编辑的卡片前走已有草稿关闭流程，取消则保持当前类型。

验证计划：最小Debug构建；实际隔离数据库混合文本/图片，检查类型切换、恢复全部、搜索组合、刷新保留筛选；启动应用体验。

## 2026-10-06：取消固定恢复自动隐藏

顶部固定状态由共享历史模型持有，A/B顶部按钮读取同一状态，不能各自保存本地固定副本。取消固定后，切换到外部应用必须恢复下滑隐藏；同时监听外部应用激活与窗口失焦，不依赖单次resignKey通知。取消固定时已在外部应用也评估隐藏。正文编辑会话仍保护草稿，不强行关闭编辑。验证最小构建、状态/焦点事件逻辑及运行，物理切换效果按实际体验验收。

### 2026-10-08 教程滑动提示修正
第二步“试着左右滑动”与“搜索任意”同高，位于筛选按钮右侧；按控件实际 anchor 与可用宽度定位，不新增背景高度。卡片完整可见，提示附近柔边模糊与阴影。用户实际向两边滚动各24pt后停留0.9秒、easeInOut淡出0.45秒并自动进入预览教学；筛选完成同样自动过渡，删除手动继续按钮。首次排版、程序滚动不计入完成条件。退出/重启取消过期等待。

### 2026-10-08 鼠标边缘反向响应
普通鼠标边缘回弹期间反向滚动必须立即接管；方向切换结束旧适配手势，新输入以began提交。仅反向且clip越界时结束旧弹性位移并恢复原生弹性，正常区间不改位置。触控板原始phase/momentum和预览正文保留。原生合成输入检查不能替代物理滚轮体验验收。

### 2026-10-08 首次呼出概念
第一步不用箭头。真实教程剪贴板在当前屏幕底边露出自身高度约1/3，快速露出后以24/8/2.5pt递减的抛物线回弹，再停顿；上方显示实际快捷键键帽与“呼出剪贴板”。半露出阶段不接受卡片输入，也不向辅助功能暴露屏幕外控件。快捷键触发后同一窗口继续升至完整位置；隐藏/退出停止循环。减少动态效果时静止露出。

最后“开始使用”自动推进，无点击按钮。真实数据库首批记录预加载后，教程卡片向下退场，真实卡片从底部向上入场；背景和搜索栏保持位置，位移按实际卡片容器高度计算。真实空库/读取错误使用正常历史状态，不将教程示例写入真实库。

默认文字卡片：内容区域内垂直居中（不含来源/时间底栏），短文居中、长文自然占满可用高度；保留文字左对齐。

### 触控板物理边缘呼出（2026-10-08）
程序运行时，双指从触控板上半区向上滑至物理上边缘可呼出，与快捷键进入同一剪贴板/教程流程。每次接触只触发一次，已展开时不因此隐藏。鼠标位置不作为命中条件，不拦截系统滚动。第一步仅在当前触控板监听可用时展示双指上滑方式。技术边界为动态加载私有MultitouchSupport，不保证未来系统/所有设备支持，缺失时保留快捷键；不改变沙盒/权限配置。

- 补充（2026-10-08）：从触控板顶边反向双指下滑收回；支持呼出后不抬手反向，或重新落指从顶边下滑。隐藏时下滑不做反向呼出，显式收回沿用草稿保护，pin仅阻止自动失焦隐藏。
