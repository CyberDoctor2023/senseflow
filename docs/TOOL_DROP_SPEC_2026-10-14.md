# 顶部工具拖放

目标：左侧保留筛选，中间区域以无标题圆球呈现工具目标；将文字卡片拖入目标，松开执行对应工具，使用完整卡片文字，不先改写剪贴板。目标进入时放大、抬升、阴影反馈，离开恢复；执行期间禁用重复提交，错误可见。图片/录屏不进入纯文本工具。

快捷键：保留全局呼出 Command+Shift+V；顶部工具按当前显示顺序提供窗口内 Command+Shift+1…9。已有用户自定义全局键不擅自覆盖。编号与工具提示对应，不增加新的全局数字注册。

非目标：本次不修改预置 prompt 和商业化模型服务，不将图片伪装成文字。

验收：左右分区清晰；拖放全文只执行一次；取消不执行；加载失败提示；设置修改后再次呼出刷新；构建、原生 UI 查看和实际拖放验证。吸附效果的视觉验收需实际运行，不能以编译代替。

引用：Apple DropDelegate https://developer.apple.com/documentation/swiftui/dropdelegate （Apple Doc MCP 已查询）；Paste 窗口内快捷键 https://pasteapp.io/help/keyboard-shortcuts 。

## 工具与圆球同步合同
圆球只呈现同一工具仓库中的工具，不能有单独的创建/删除配置。订阅已有 promptToolsDidUpdate 通知，在主线程触发刷新；刷新任务取消旧请求，忽略过期返回。新增、删除、修改与恢复默认工具均实时反映。执行仍按 ID 从仓库读取当前工具，UI 不持有提示词执行逻辑。

## 卡片吸附修正
工具组移入筛选与 pin 之间的中间区域，两侧弹性留白；不固定在右上角。原生 AppKit 拖放目标负责整张卡片拖拽图像的缩放与目标吸附，包含卡片背景、文字和 footer；不是只拖文字。使用 updateDraggingItemsForDrag 和 animatesToDestination，避免每次指针更新重算图片。退出目标恢复卡片尺寸，取消由系统回原位。UI 只发送文字载荷给现有工具执行入口。

卡片吸附修正构建：build-card-tool-drag.log BUILD SUCCEEDED；diff --check 通过。已备份、安装并启动。Apple Doc MCP 确认 updateDraggingItemsForDrag、enumerateDraggingItems、animatesToDestination；依 SDK NSDragging.h 确认签名。此前 onDrop 的圆球反馈路径已替换，保留单一原生拖放目标。实际卡片吸附视觉与窗口内拖放验收仍未完成；不以构建通过认定体验通过。

## 活体卡片拖动与预览工具底座
移除工具组文字。拖动时采用独立、鼠标穿透的原生玻璃卡片呈现，复用同一内容/底栏视图，不以文件图标或截图作为可见主体；原生拖放仅传输载荷。按指针移动完整卡片，进入工具范围时轻微吸附，松开收向目标，取消回原卡片槽。预览定位按真实工具表面屏幕坐标确定底边，固定小间距；点击工具不关闭预览，文字输入取当前预览的编辑快照。工具数据仍只有仓库一套。

## 上下文出现合同（最新）
圆球不常驻。仅在卡片原生拖动期间，或长按受理后的预览加载/打开期间显示；拖动结束且没有预览时收回。macOS 26 使用 glassEffectTransition(.materialize)，配合原生 SwiftUI 缓入缓出；减少动态效果时禁用动画。当前预览允许直接使用工具，关闭预览即收回；短按粘贴不显示工具。

按压微反馈补充：按下立即呈现 65% 尺寸、35% 不透明度的圆球趋势，不可点击；既有 450ms 长按被受理或启动拖动时，用原生 spring(duration:bounce:) 完整出现。短按松开收回，不新增独立等待定时器。只记录当前按压卡片 ID，其他卡片的取消回调不能清除正在按压的卡片状态。

## 原生融合合同修正
