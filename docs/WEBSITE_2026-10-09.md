# senseflow.top 官网与 Cloudflare

目标：建立产品官网，托管到 Cloudflare Workers Static Assets，连接阿里云注册的 senseflow.top。域名不转移注册商。页面独立在 website/，不影响 macOS 工程。

首版：小写品牌、苹方优先、真实产品能力、公开示例卡片、现有 GitHub 预发布下载入口（标明测试版与 Apple Silicon）。不上传用户历史、截图或配置；不宣称未实现的云同步/商业 AI/已公证安装包。不添加登录、支付或埋点。

接入：先核验 Cloudflare 账号、域名 zone、现有 DNS 记录和 DNSSEC，再准备站点与自定义域名；确认现有 MX/TXT 等记录保留后修改阿里云 nameservers。不猜测 Cloudflare 分配的 nameservers。登录/验证由用户完成；切换 DNS 前保留原记录备份。根域 `senseflow.top` 作为 Worker 自定义域名，首版不额外添加 `www`。

验收：Wrangler dry-run、桌面/手机可读且链接可用，本地页面截图；成功部署需实际 workers.dev HTTPS 响应；域名完成需 Cloudflare zone active 与 senseflow.top HTTPS 验证。未登录或 DNS 未生效如实记录，不能标为上线。

官方依据：
- https://developers.cloudflare.com/workers/static-assets/get-started/ （支持无框架静态网站部署）
- https://developers.cloudflare.com/workers/configuration/routing/custom-domains/
- https://developers.cloudflare.com/dns/zone-setups/full-setup/setup/

结果：站点已部署到 `senseflow-website.ilovecyberhk.workers.dev`，并将 `senseflow.top` 配置为 Worker 自定义域名。阿里云原解析记录为 0，DNSSEC 未配置；原名称服务器为 `dns17.hichina.com` / `dns18.hichina.com`。2026-10-10 已在阿里云将名称服务器修改为 Cloudflare 分配的 `hattie.ns.cloudflare.com` / `julio.ns.cloudflare.com`，Cloudflare 控制台已确认域状态为“活动”，DNS 中存在指向 `senseflow-website` 的已代理 Worker 记录。切换前页面快照保存在 `out/2026-10-09-website/aliyun-dns-before.txt`。

验证：Wrangler dry-run 通过；最终部署同时保留 `workers.dev` 地址并关闭非必要的版本预览 URL。Cloudflare 公共 DNS 已返回新的 NS 与根域边缘地址；通过两个 Cloudflare 边缘地址请求 `https://senseflow.top/` 均返回正确站点，其中首页标题为 `senseflow — macOS 剪贴板`。部分递归 DNS 在其旧 TTL 到期前仍可能返回阿里云旧名称服务器。本机 Surge fake-IP 和缓存不能用于判断公网解析状态。

## 2026-10-10 产品演示重构

目标：官网采用白底为主的黑白视觉，移除暖黄底色和大面积黑底。首屏中的剪贴板演示与当前产品共用关键布局参数：280×36 搜索胶囊、36×36 分类按钮、4pt 工具栏间隔、236pt 卡片区高度、180×180 卡片、20pt 圆角、16pt 卡片间距、28pt 容器内边距、1.04 悬停抬升比例，并复现文字/图片/代码/截图/录屏筛选、固定按钮、卡片来源栏和玻璃层次。官网不得增加产品里没有的“全部”按钮、操作提示或键盘焦点框。

品牌文案：品牌名始终写作小写 `senseflow`；“感觉流动”是其中文翻译。首屏产品介绍只使用“一个更好用的 macOS 剪贴板”。删除“原生 macOS 剪贴板”和其他宣传口号，后续标题只标明功能或下载动作。

演示行为：卡片默认连续水平流动；悬停、键盘聚焦或页面不可见时暂停。官网演示不叠加“左右滑动”文字或双指引导动效；悬停使用中性阴影和整卡抬升。持续动画只修改 transform/opacity，不连续修改布局、模糊或大面积滤镜；尊重 `prefers-reduced-motion`。

功能内容：展示历史翻看与搜索、五类筛选、长按/按压预览、长文阅读与编辑另存、固定与拖入焦点窗口、截图与录屏聚合，以及翻译、格式整理、摘要等“一组工具”。工具能力按现有产品方向描述，不宣称 RAG、云同步或尚未上线的模型托管。

下载：所有主要下载按钮直接指向 `https://github.com/CyberDoctor2023/senseflow/releases/latest`，不写死版本标签。新版本完成验证并发布为 GitHub 正式 latest 后，官网无需再次改链接。

完成条件：桌面和移动端无水平页面溢出；剪贴板演示可读、可暂停，筛选按钮能实际切换演示内容；下载按钮全部使用 latest 地址；Wrangler dry-run 与线上 HTTPS 内容验证通过。
