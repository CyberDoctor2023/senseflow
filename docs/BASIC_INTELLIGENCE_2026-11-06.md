# 基础智能：来源过滤与完整片段覆盖

日期：2026-11-06。状态：两个开关与采集链路已实现，构建及隔离回归通过。微信输入法真实语音来源归因、设置页实际点击仍待完成。

## 目标与非目标

设置新增“基础智能”，包含两个独立、可选开启的功能：

1. 自动过滤无用内容：按真实写入来源过滤语音输入法为完成输入而写入剪贴板的记录。优先验证微信输入法，随后按证据支持豆包、Wispr Flow、Typeless。不是删除正文口头禅，也不是按目标输入应用排除。
2. 完整片段覆盖：后续完整文本精确包含先前短片段时，仅保留完整片段。时间/来源范围、原文与草稿保护、恢复策略须在实现前明确；本次不扫描删除既有历史。

不改写系统剪贴板，不影响输入法完成粘贴，不凭输入法运行中/当前选中就过滤普通复制，不将相似语义视为完全覆盖。

## 外部依据与限制

- NSPasteboard 社区约定支持 org.nspasteboard.source（写入方主动提供的 bundle ID），以及 TransientType / AutoGeneratedType 等标记。标记是可选约定，不能假定微信输入法实现。https://nspasteboard.org/
- Apple NSPasteboard 文档与当前 SDK 公开头文件：changeCount、types 可读；本次未发现公开的直接获取最后写入进程 PID 的接口。owner 参数用于提供延迟数据，不等于写入者身份查询。https://developer.apple.com/documentation/appkit/nspasteboard
- Apple CGEventField.eventSourceUnixProcessID 是事件来源进程 PID；它是键盘事件身份，不是剪贴板写入身份。可与微信输入法自动 Cmd+V、剪贴板 changeCount 关联做候选识别，尚未实测可靠性。https://developer.apple.com/documentation/coregraphics/cgeventfield/eventsourceunixprocessid
- listenOnly 事件 tap 可被动观察，不修改/消费事件。实际权限及是否能看到该输入法事件须实测。https://developer.apple.com/documentation/coregraphics/cgeventtapoptions/listenonly
- Apple Doc MCP 成功返回 AppKit changeCount；NSPasteboard/MetadataType 查询 404，CoreGraphics 技术名称未解析，改查 Apple 官方页面及当前 Xcode SDK 公开头文件。
- 微信官网 z.weixin.qq.com 本次抓取失败。网上未找到能证明微信 macOS 语音剪贴板携带特定标记的官方说明。wetype.tech 是其他开发者产品，不能当腾讯微信输入法的依据。
- Wispr Flow Backtrack 与 Typeless 正文清理功能已查阅，但与用户澄清后的来源过滤是不同需求，不据此实现正文改写。https://docs.wisprflow.ai/articles/5373093536-how-do-i-use-smart-formatting-and-backtrack ; https://www.typeless.com/

## 下一步验证计划与完成条件

先用真实微信语音输入与同一目标应用里的手动 Cmd+C 做对照，采集仅含时间、changeCount、types、来源标记、Cmd+V 来源 PID/bundle ID 的元数据，不记录正文或所有按键。覆盖输入中、结束、剪贴板恢复及普通复制竞争。只在观察到可靠来源证据后选定实现；无证据时保留记录，不能用前台应用或文本内容猜测。

实现前补全两个独立开关默认值、判定边界与短片段恢复合同。验证需包括关闭后原行为、微信自动写入过滤、普通复制保留、其他应用不误伤、完整文本原文保留、草稿/编辑会话保护及事务失败不丢数据。最后运行一次 focused build、隔离持久化验证和真实设置界面体验；未执行的项目明确列为未验证。

## 实施合同

- 两个独立开关默认关闭，设置增加“基础智能”独立页面。
- 来源过滤采用 org.nspasteboard.source 的明确 bundle ID，及真实输入法合成 Cmd+V 的来源 PID 与同一 changeCount 关联。输入法名单先支持本机可核验的微信输入法。被动事件观察失效时设置展示状态，并继续依据可用来源标记判定。
- 完整片段覆盖限定启用期间采集的最近 50 条候选、同一来源应用、120 秒内、4 至 4096 字符短片段与最长 65536 字节完整文本。逐字包含且严格变长才覆盖。来源过滤独立生效。
- 覆盖以 SQLite 关联保存，在列表及搜索分页前隐藏短片段。关闭开关恢复显示，删除完整片段恢复其短片段，再次手动复制短片段恢复显示。原文详情持续可读。草稿、已保存版本及其来源排除覆盖。候选集合有界且仅由串行 store 队列持有。
- 关联更新与采集写入同一事务。新增关联表前创建 SQLite 备份。完成文本保留原样，不加载图片原件做判断。
