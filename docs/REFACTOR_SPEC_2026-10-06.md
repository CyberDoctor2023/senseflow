# SenseFlow 重构范围与验收规格

日期：2026-10-06。状态：计划完成，产品实现未开始。产品基础规范仍为 `docs/SPEC.md`；本规格覆盖与本次需求冲突的旧色条、固定预览及性能宣称。

## P0 稳定性补充

用户补充无提示闪退。已取得 2026-10-06 的真实 OCR continuation 致命断言报告，详见 `CRASH_REVIEW_2026-10-06.md`。重构必须先修此问题；普通 OCR 失败不终止进程、不损坏历史，下次启动提供异常会话诊断入口。OCR 已移除 continuation 双恢复路径，真实 Vision 空结果及坏图片验证通过；不能据此宣称所有闪退已消除，详见 `DOCUMENT_IMPLEMENTATION_VALIDATION_2026-10-06.md`。

## 长文本核心体验补充

用户明确优先级：鼠标划过历史长文本时弹出类似 Word 的原生文档窗口，支持完整阅读和编辑。产品合同见 `prd/LONG_TEXT_DOCUMENT_PREVIEW.md`，模块、事件、存储、窗口焦点与迁移合同见 `design/LONG_TEXT_DOCUMENT_PREVIEW.md`；它们覆盖旧“仅选中/Space 打开只读详情”的方案。

本轮完成条件增加：明确 hover→阅读→编辑状态、原文/草稿/保存语义、解耦接口、超长内容性能预算、异常退出恢复与逐项验收。仅完善 PRD/设计，不开始产品实现。默认纯文本编辑、自动草稿、显式保存新记录；保留原始捕获，未来若改变此政策必须先改规格。

## 目标

以“方便找回和预览的原生 macOS 剪贴板”为核心，优先解决卡顿；去除类型色条和用户可见 AX 调试内容；长文本按内容自适应预览；快捷键执行翻译、格式化等可定制固定 workflow。精简项目与全局 AGENTS.md，保留研究、数据安全和真实验收要求。

## 非目标

最初审查阶段只形成计划和指导文档，不修改产品或运行构建。用户后续授权进入实现，当前范围以本文末尾“实施授权”与 `DOCUMENT_IMPLEMENTATION_VALIDATION_2026-10-06.md` 为准。暂不全量重写 UI、不删除尚未证明无用的功能、不新增云同步或自主桌面 Agent。embedding/RAG 不进入首屏、复制、关键词搜索的关键路径。

## 完成条件

1. 审查结果区分可直接证实的问题、静态风险、需运行确认的瓶颈；每项有文件与行号。
2. 计划覆盖性能、原生界面、自适应预览、工具、依赖与目录清理、数据迁移和回滚。
3. 性能数字标为拟定目标，不能沿用旧文档的无证据“已通过”。
4. 全局/项目规则精简前有备份，专属规则迁出但可找回；cc-switch 与运行时规则同步且保留旧 prompt。
5. 不因模型升级移除数据保护、官方事实核验或测试证据要求。

## 验证计划

本轮对照源代码检查文档引用、文件路径、备份完整性和规则一致性；不声称构建、运行体验或性能测试通过。实施阶段按计划执行 focused tests、原生界面实测与 Instruments 前后对比；取得真实数据才宣告优化完成。

## 建议实现契约

- 历史、原文、图片原件、工具配置与快捷键必须保留；迁移前备份，失败不覆盖原数据。
- 卡片 body 不执行磁盘 I/O、图片解码、SQL 或全文分析。列表只读轻量摘要，原文与原图按需载入。
- 数据库的完整业务操作具有单一并发所有者；重复复制更新同一记录的 recency，不删除重建稳定 ID。
- 同一数据状态只发起一次刷新；搜索仅接受最新请求结果；错误与空结果区分。
- 卡片去掉蓝紫色条，采用中性背景、可读字体、来源与时间。类型可由内容或小图标表达。
- 长文本悬停后进入 Word 风格原生文档窗口：全文阅读，点击正文开始编辑并固定窗口；短文本按内容适配。窗口有屏幕边界和滚动上限，不以固定 8 行冒充全文。编辑、草稿、保存、复制与粘贴分别定义，详见长文本 PRD。
- 用户界面不显示 AX 节点、role/ref 或内部 trace；保留自动粘贴所需 Accessibility 能力。
- 本地格式化无需模型；翻译/润色/总结按用户配置调用模型。工具显式输入、可取消、错误可见；结果先预览，复制/替换由明确操作控制。

## 待实施时确定

最低系统版本以现有工程 target 为事实，当前存在 14.0/14.6/15.6 不一致；建议首阶段保留现有兼容范围，统一 target 后再决定是否提高到 macOS 26。可选语义检索的模型、存储、隐私与成本应另立规格，不能凭宣传词引入后台负担。
